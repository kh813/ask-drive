# 窓口管理者のスタートアップガイド

AskDrive で、自分の部門の「窓口（アプリ）」を使い始めるまでの手順です。
むずかしい設定はシステム管理者が済ませているので、窓口管理者は **Step 1 から順に** 進めれば大丈夫です。

> **問い合わせるときは**: 「Step 3-2 まで終わりました」「Step 3-3 で赤いメッセージが出ました」のように、**どの Step まで終わったか** と、**画面に出ているメッセージ** を伝えてください。すぐに状況が分かります。

---

## はじめに: 言葉の意味

| 言葉 | 意味 |
|---|---|
| **窓口（アプリ）** | 部門ごとの質問コーナーです。例: 人事部の「HR」、情報システム部の「IT-Support」。窓口ごとに、使う資料・設定・質問の記録が分かれています |
| **窓口管理者** | 窓口の担当者です（このガイドを読んでいるあなた）。**自分の担当の窓口だけ** を管理できます。ほかの窓口や、AskDrive 全体の設定は変えられません |
| **システム管理者** | AskDrive 全体を管理する人です（画面上は「全体管理者」）。窓口を作ったり、窓口管理者を決めたりします |
| **管理画面** | 窓口の設定をする画面です。チャット画面とは別にあります |
| **API キー** | クラウドの AI を使うための「鍵」です。パスワードと同じように大切に扱います |
| **取り込み** | Google Drive の資料を AskDrive に読み込むことです。読み込んだ資料をもとに、AI が質問に答えます |

---

## 全体の流れ（チェックリスト）

| Step | やること | だれが | 終わった目印 |
|---|---|---|---|
| **Step 1** | 窓口の作成と、窓口管理者の設定を依頼する | あなた → システム管理者 | 窓口の管理画面に入れる |
| **Step 2** | 自分の部門の API キーを確認する（なければ発行を依頼） | あなた → 部門の Google Cloud 担当者 | API キーを受け取った |
| **Step 3** | Google Drive をつなぎ、資料のフォルダを指定する | あなた | 「同期テスト」でファイルの数が表示される |
| **Step 4** | API キーを設定する | あなた | 「接続テスト」が成功する |
| **Step 5** | 資料を取り込む | あなた | 「ドキュメント一覧」に資料が並ぶ |
| **Step 6** | チャットで試す | あなた | 資料にもとづいた回答が出る |
| **Step 7** | 利用者に窓口を案内する | あなた | 利用者が使い始める |

---

## Step 1. システム管理者に、窓口の作成と窓口管理者の設定を依頼する

### Step 1-1. 依頼する

システム管理者に、次の 3 つを伝えて依頼します。

- **窓口の名前**（例: 人事相談、HR）
- **URL に使う名前**（英小文字と数字。例: `hr`）。窓口のアドレスの最後の部分になります
- **窓口管理者にする人のメールアドレス**（会社の Google アカウント。複数人でも可）

### Step 1-2. 窓口の管理画面に入れることを確認する

1. システム管理者から、窓口ができたと連絡が来たら、AskDrive をブラウザで開き、会社の Google アカウントでログインします。
2. 画面の上の左側にある **「（窓口名）の管理」**（例: 「HR の管理」）を押します。窓口の管理画面のアドレスは `https://<AskDrive のアドレス>/<URL に使う名前>/admin` です（例: `…/hr/admin`）。
3. 本人確認を求められたら、画面の案内に従います（会社の Google アカウントのパスワードを入れる、またはログインし直す）。

**終わった目印**: 「概要・バッチ状況」「ドキュメント一覧」「設定」などのタブが並んだ画面が表示されれば OK です。

> 「（窓口名）の管理」が見当たらない、または入れないときは、システム管理者に「窓口管理者に自分のメールアドレスが入っているか」を確認してもらってください。

> 管理画面は、しばらく操作しないと自動で閉じます（安全のため）。そのときは、もう一度「（窓口名）の管理」から入ります。

---

## Step 2. 自分の部門の API キーを確認する（なければ発行を依頼）

チャットの回答をクラウドの AI（Google の Gemini）で作るために、**部門の Google Agent Platform（旧名 Vertex AI）の API キー** を使います。AI の利用料金は、このキーを持つ部門に請求されます。

1. 部門の Google Cloud の担当者（分からなければシステム管理者）に、**「AskDrive で使う Google Agent Platform（Vertex AI）の API キー」** があるかを確認します。
2. まだなければ、発行を依頼します。そのとき、次も教えてもらいます。
   - **プロジェクト ID**（例: `my-dept-project`）
   - **リージョン**（例: 東京なら `asia-northeast1`）
   - **使うモデルの名前**（指定がある場合）

   プロジェクト ID とリージョンは、なくても動きます（処理する場所を国内などに決めたいときに使います）。

**終わった目印**: API キー（長い英数字の文字列）を受け取った。

> **API キーの扱い**: パスワードと同じです。メールやチャットにそのまま貼ったり、ほかの人に見せたりしないでください。AskDrive に入れたキーは暗号化して保存され、画面には最後の 4 文字だけが表示されます。

> システム管理者から「この窓口はローカルの AI（AskDrive のサーバーの中の AI）だけを使うので、API キーは要らない」と言われた場合は、Step 2 と Step 4 は飛ばしてください。

---

## Step 3. Google Drive をつなぎ、資料のフォルダを指定する

### Step 3-1. 資料を 1 つのフォルダにまとめる

1. 窓口で答えたい内容の資料（マニュアル、規程、よくある質問など）を、Google Drive の **1 つのフォルダ** にまとめます。フォルダの中のフォルダ（サブフォルダ）も読み込まれます。
2. 取り込める資料の種類は、[よくある質問の「どんなファイルが取り込まれますか？」](FAQ.md#q-どんなファイルが取り込まれますか) を見てください。

> 回答に使いたくない資料は、このフォルダに入れないでください（入れてしまった場合も、あとで対象から外せます）。

### Step 3-2. Google Drive をつなぐ

1. 窓口の管理画面で **「設定」** タブを開き、**「Google Drive 同期設定」** を見つけます。
2. **「同期する Google アカウントを入力」** の欄に、Step 3-1 のフォルダを見られる Google アカウントのメールアドレスを入れます。
3. **「Google の認可画面を開く（別ウィンドウ）」** を押します。別のウィンドウで Google の画面が開くので、そのアカウントでログインし、**「許可」** を押します。
4. 許可したあとの動きは、使っているパソコンによって違います。
   - **自動で戻ってきた場合**: そのまま次へ進みます。
   - **別ウィンドウに「このサイトにアクセスできません」などと表示された場合**: 故障ではありません。そのウィンドウの **アドレス欄の文字（`http://localhost:4000/auth/google/callback?…` で始まるもの）をすべてコピー** し、管理画面の貼り付け欄に貼って **「保存して認証完了」** を押します。

**終わった目印**: カードに **「Google Drive 接続済み」** と表示されれば OK です。

> 「OAuth クライアント」が必要というメッセージが出たときは、システム管理者の準備が済んでいません。そのメッセージをシステム管理者に伝えてください。

> つないだ Google アカウントの人が異動・退職すると、資料を読み込めなくなります。担当者に左右されない方法（サービスアカウント）に変えたいときは、システム管理者に相談してください。

### Step 3-3. 資料のフォルダを指定する

1. Google Drive で、Step 3-1 のフォルダを開きます。
2. ブラウザの **アドレス欄の URL をそのままコピー** します（例: `https://drive.google.com/drive/folders/1AbC…`）。
3. 管理画面の **「同期するフォルダ」** の **「Google Drive フォルダ ID / URL」** 欄に貼り付けます。
4. **「フォルダの表示名（任意）」** に、分かりやすい名前（例: 人事マニュアル）を入れます。
5. **「保存」** を押します。保存すると、URL からフォルダの ID（フォルダを表す英数字）が自動で取り出され、欄には ID だけが表示されます。

> 「フォルダではなくファイルのリンクです」と出たときは、ファイルを開いた状態のアドレスを貼っています。フォルダを開いた状態で、アドレス欄の URL をコピーし直してください。

### Step 3-4. 同期テストで確かめる

1. **「同期テスト」** を押します（資料はまだ読み込まれません。確認だけです）。

**終わった目印**: 読み込みの対象になる **ファイルの数と、ファイル名の例** が表示されれば OK です。

> ファイルの数が 0 のときや、エラーが出たときは、Step 3-2 でつないだアカウントがそのフォルダを見られるか（共有されているか）を確認してください。

---

## Step 4. API キーを設定する

1. 窓口の管理画面の **「設定」** タブで、**「LLM プロバイダ」** の設定を見つけます。
2. **「チャット要約の実行方法」** を **「クラウド API」** にします。
3. **「チャット要約のクラウド API プロバイダ」** で **「Google Agent Platform (Vertex AI)」** を選びます。
4. すぐ下に出る **「Agent Platform（Vertex AI）の API キー」** の欄に、Step 2 で受け取った API キーを貼り付けます。プロジェクト ID とリージョンを教えてもらっていれば、それも入れます。
5. **「チャット要約モデル名」** を、表示される候補から選びます（どれを選べばよいか分からないときは、Step 2 で API キーを発行した人かシステム管理者に確認してください）。
6. 画面の下の **「設定を保存」** を押します。
7. **「接続テスト」** を押します。

**終わった目印**: 接続テストが成功と表示されれば OK です。

> 保存したあとは、API キーの欄に「設定済み: ••••••••（最後の 4 文字）」と表示されます。キーを変えるときだけ入力してください。空のまま保存しても、キーは消えません。

> 夜に自動で行う「想定問答（QA）の作成」にもクラウドの AI を使えますが、利用料金が増えます。使うかどうかは、システム管理者と相談して決めてください。

---

## Step 5. 資料を取り込む

1. 窓口の管理画面の **「概要・バッチ状況」** タブを開きます。
2. **「取り込みのみ実行」** を押します。資料の量にもよりますが、数分で終わります。実行中もチャットは使えます。
3. 終わったら、**「ドキュメント一覧」** タブで資料が並んでいるかを確認します。

**終わった目印**: 「ドキュメント一覧」に資料が並んでいれば OK です。

> 取り込めなかった資料があるときは、「概要・バッチ状況」の **「ファイル別ログ」** に理由が出ます。

> このあとは、**毎晩自動で** Drive の資料が読み込み直されます。資料を Drive で更新すれば、翌朝には回答に反映されます（すぐに反映したいときは、もう一度「取り込みのみ実行」を押します）。

---

## Step 6. チャットで試す

1. 窓口のチャット画面（`https://<AskDrive のアドレス>/<URL に使う名前>`。例: `…/hr`）を開きます。
2. 資料に書いてあることを質問してみます（例: 「有給休暇は何日？」）。

**終わった目印**: AI の回答の下に、**番号付きの「引用元」**（資料の名前とページ）が表示されれば OK です。

> 思った回答にならないときは、資料にその答えがはっきり書かれているかを確認してください。よく聞かれる質問は、質問と回答をまとめた「FAQ の資料」を Drive に置くと、正確に答えやすくなります（書き方は README の「窓口の FAQ 文書を作る方へ」を参照）。

---

## Step 7. 利用者に窓口を案内する

1. 利用者に、窓口のチャット画面のアドレス（Step 6 の 1 のアドレス）を伝えます。
2. 必要なら、次の設定もできます（どちらも「設定」タブ）。
   - **特定の部署の人だけに使わせたい**: 「窓口アクセスパスワード」でパスワードを保存し、「パスワードによる利用制限」をオンにします。
   - **窓口管理者を増やしたい・引き継ぎたい**: 「窓口の担当者」でメールアドレスを追加します。自分を外して引き継ぐこともできます（最後の 1 人は外せません）。

**これで準備は完了です。**

## 使い始めてから

| 見たいこと・やりたいこと | 場所 |
|---|---|
| 答えられなかった質問を確かめる | 「未回答・解消質問」タブ |
| どれくらい使われているかを見る | 「利用状況」タブ |
| 取り込んだ資料を確かめる・回答に使わない資料を外す | 「ドキュメント一覧」タブ |
| 夜の自動実行がうまくいったかを見る | 「概要・バッチ状況」タブ |

よくある質問は [docs/FAQ.md](FAQ.md) にまとめています。

## 窓口管理者にはできないこと（システム管理者に依頼すること）

次のことは AskDrive 全体にかかわるため、窓口管理者の画面にはありません。必要なときはシステム管理者に依頼してください。

- 窓口の作成・名前や URL の変更・削除
- ログインの方法や、会社のドメインの設定
- AskDrive 本体のアップデート
- サーバーの中の AI（ローカルの AI モデル）の追加
- Google の「OAuth クライアント」の登録（Step 3-2 で必要になるもの）
